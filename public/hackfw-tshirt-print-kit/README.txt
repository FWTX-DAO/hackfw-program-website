PRINT-SIZE AND FORMAT NOTES

- BNSF (310 x 70), LiquidAcre (600 x 107), United Way of Tarrant County
  (440 x 150), and DFW Code & Coffee (300 x 250) are small raster sources.
  Check their effective resolution at the intended print size. Request
  vector or larger originals if these files cannot meet the printer's needs.
- MoonShot and United Way of Tarrant County are WebP; Fort Worth DAO is AVIF.
  The printer may need compatible exports or original brand files.
  Format conversion does not add resolution.
- Y2 contains gradients and transparency. Check reproduction in the selected
  print process, particularly if a single ink color is planned.
- SVG files are supplied as received; check import and output in the
  printer's production software.
- Agent Builders Club includes a black background. DFW Code & Coffee has
  transparent padding and a white ampersand. Preserve the supplied artwork
  and account for these backgrounds and margins in the layout proof.
